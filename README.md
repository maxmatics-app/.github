# Welcome to Maxmatics App 👋

**Maxmatics App** is a software organisation building smart, mathematics-focused applications and tools.

---

## 🚀 What We Do

We design and develop applications that make mathematics accessible, engaging, and powerful for everyone — from students learning the basics to professionals working on complex problems.

Our projects span:

- 📱 **Interactive learning apps** — hands-on tools that bring maths concepts to life
- 🔧 **Developer utilities** — libraries and APIs for mathematical computation
- 📊 **Data & visualisation tools** — turning numbers into insights

## 🤝 Contributing

We welcome contributions from the community!  
If you'd like to contribute to one of our projects, please:

1. Fork the relevant repository
2. Create a feature branch (`git checkout -b feature/your-idea`)
3. Submit a pull request with a clear description of your changes

For major changes, please open an issue first to discuss what you'd like to change.
